CI Operator Emulator

During the test and development phase, it will be significantly more efficient if the CI OperatorStep script can be executed in local env., instead of being executed via CI OperatorJob rehearsal (as it takes time to schedule it, not to mention it is a non-interactive session so real-time inspection can not be performed).

Since the CI OperatorStep script is executed inside a Container, it should be possible to start a local Container using the same Container Image used to execute theStep. Having an interactive local Container improves the development cycle due to faster iteration forStep script re-execution. What is needed is this Container Image.

This tool will automate the creation of Pre-Test (run all previousStep s before targetStep ) and Image Retrieval (build the targetStep Container Image) CI OperatorJob s, so they can be pushed to a dummy GitHub Pull Request (PR).

After the Pre-TestJob rehearsal, the test environment can be synchronized locally, to bring it on par with CI execution just before executing the target Step. The target Step Container Image can also be downloaded.

Alternatively, the Pre-TestJob may be skipped if synchronizing the test environment is not deemed necessary (in some situations this may be warranted). Instead the Image RetrievalJob can be rehearsed. After this rehearsal (which should be quick), the Container Image can be downloaded (within a certain amount of time, before theJob 'sNameSpace in the executing CI Operator Build Cluster is deleted). Generally speaking we only need to do this once for every unique Container Image used to execute theStep.

Once the test environment is on par with CI execution before target Step and the Container Image is available locally, the Container (with environment settings that mimic the Container created on the CI Operator Build Cluster) can be started. And inside this local Container, the correspondingStep Script can be executed with much faster iteration and providing real-time inspection capabilities that can not be done duringJob rehearsal.
