--- --- {%- include jekyll/url.var -%} VM Image Hosting Structure 
AWS S3 Bucket:
  - ISO Image:
    <s3BucketName>/
     |- windows
         |- <osName>/
             |- <osVer>--<osBuid>.<osRev>.iso
  - OS Image - Windows:
    <s3BucketName>/<osName>/
     |- build                                   # Specialized final version to build the template from.
     |   |- <osVer>--std--<YYmmdd>.qcow2        # Standard Windows with basic Apps.
     |   |- <osVer>--cbi--<YYmmdd>.qcow2        # With CloudBase-Init installed.
     |- dist/
     |   |- <osVer>--template--<remarks>.qcow2  # VM Image Template (generalized).
     |- draft/
         |- <osVer>--stage--<remarks>.qcow2     # Any temporary images.
