Cluster Profile

The Cluster Profile metal-redhat-gs has been registered via PRs on openshift/ci-tools repo. and openshift/release repo.

The firewall and DNS Zone has been configured to allow connection from CI Operator Test Pod to the cluster.

To use this Cluster Profile in the CI Operator Job, it need to run on Build Cluster that has intranet Capatility. This can be done by setting capabilities key accordingly in the CI Operator config file.
