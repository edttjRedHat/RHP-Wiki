Current Information

Information on the installed OCP Cluster can be retrieved from BitWarden Note.

solidOCP Cluster Information 
( set -euo pipefail; shopt -s inherit_errexit
    bwNoteName='note.HWcluster--GoldmanSachs'
    export BW_SESSION="$((bw status | grep -q '"status":"unlocked"') && echo "${BW_SESSION}" || bw unlock --raw || bw login --raw)"
    [ -n "${BW_SESSION}" ] && bw sync || {
        echo 'You do NOT have an active and sync:ed BitWarden Session!!!' 1>&2
        exit 1
    }
    bwData="$(bw get item "${bwNoteName}")" || {
        echo "You may NOT have access to BitWarden Note \`${bwNoteName}\`." 1>&2
        exit 1
    }
    trap 'tput cnorm; tput rmcup' EXIT
    tput smcup; tput civis
    i=4 t=10
    while ((i--)); do
        clear
        case $i in
          (3)
            echo 'General Information.'
            echo "${bwData}" | jq -r '.notes'
            ;;
          (2)
            echo 'Accessing BMCs.'
            echo "${bwData}" | jq -r '.fields[]? | select(.name == "BMC").value'
            ;;
          (1)
            echo 'Serial Console Credential.'
            echo "${bwData}" | jq -r '.fields[]? | select(.name == "SerialConsole").value'
            ;;
          (0)
            echo 'Accessing Nodes.'
            echo "${bwData}" | jq -r '.fields[]? | select(.name == "NodeAccess").value'
            ;;
        esac
        REPLY=' ' j=t
        while ((j)); do
            tput cr; tput el
            printf '%s %s %s' \
                'Press [SPACE] key to stay on this page' \
                "(timeout in $((j--)) sec.)" \
                'or any OTHER key to continue now...'
            read -srn 1 -t 1 || continue
            [ "${REPLY}" = ' ' ] && j=t || break
        done
    done
true )

solidOCP Cluster KUBECONFIG 
( set -euo pipefail; shopt -s inherit_errexit
    bwNoteName='note.HWcluster--GoldmanSachs'

        bw get item "${bwNoteName}" |

        exit 1
    }

Updating KUBECONFIG

solidOCP Cluster KUBECONFIG 
( set -euo pipefail; shopt -s inherit_errexit
    bwAttFilePath='<span style="color:red;font-weight:bold;">...pathToKubeConfigFile...</span>'
    bwNoteName='note.HWcluster--GoldmanSachs'
    export BW_SESSION="$((bw status | grep -q '"status":"unlocked"') && echo "${BW_SESSION}" || bw unlock --raw || bw login --raw)"
    [ -n "${BW_SESSION}" ] && bw sync || {
        echo 'You do NOT have an active and sync:ed BitWarden Session!!!' 1>&2
        exit 1
    }
    bwItemID="$(bw get item "${bwNoteName}" | jq -r '.id')" || {
        echo "You may NOT have access to BitWarden Note \`${bwNoteName}\`." 1>&2
        exit 1
    }
    while IFS='' read -r e; do
        bw delete --itemid "${bwItemID}" attachment "${e}" || {
            echo "You do NOT have R/W access to BitWarden Note \`${_BW__NOTE_NAME}\`." 1>&2
            exit 1
        }
    done 0< <(
        bw get item "${bwNoteName}" |
        jq -r '(.attachments // [])[] | select(.fileName == "kubeconfig") | .id'
    )
    bw create --file "${bwAttFilePath}" --itemid "${bwItemID}" attachment 1> /dev/null
true ); echo $?

Cluster Profile

The Cluster Profile metal-redhat-gs has been registered via PRs on openshift/ci-tools repo. and openshift/release repo.

The firewall and DNS Zone has been configured to allow connection from CI Operator Test Pod to the cluster.

To use this Cluster Profile in the CI Operator Job, it need to run on Build Cluster that has intranet Capatility. This can be done by setting capabilities key accordingly in the CI Operator config file.

yamlci-operator/config/<GitHubOrg>/<GitHubRepo>/<GitHubOrg>-<GitHubRepo>-<GitHubBranch>__<JobVariantDescription>.yaml
